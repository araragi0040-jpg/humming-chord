## 参考コードの初期反映

### 1拍ごとに4拍マスへ入れる

デフォルト設定です。

同じ小節内でも、抽出コードが分かれる場合があります。

```text
1小節目: [Dm] [Dm] [Gm] [Gm]
2小節目: [Bb] [Am] [Gm] [Dm]
```

### 小節ごとにまとめて入れる

参考コードを1小節単位でまとめて入れたい場合に使います。

```text
1小節目: [Dm] [Dm] [Dm] [Dm]
2小節目: [Gm] [Gm] [Gm] [Gm]
```

## v0.9で入っていること

- 抽出コードを1小節単位ではなく、1拍ごとに推定
- 抽出した参考コードを4拍マスへ直接反映
- 3.コード進行の上部表示も、4拍マス形式に変更
- 「再生BPMでコード再生成」を押した時も、1拍ごとの参考コードを再抽出して4拍マスへ反映
- JSON出力に `beatReferenceChords` と `beatCandidates` を追加

## 使い方

1. `index.html` をブラウザで開く
2. 音声ファイルを選ぶ、または録音する
3. 推定BPM・推定キー・検出メロディを確認する
4. 「参考コードの初期反映」を選ぶ
5. 必要に応じて再生BPMを変更する
6. 必要に応じてコード全体のオクターブを変更する
7. 「再生BPMでコード再生成」を押す
8. 3.コード進行に入った4拍マスの参考コードを確認する
9. 各小節の4拍マスでコードを調整する
10. コードを再生して、ハイライトを見ながら確認する
11. 必要な形式で出力する

## v0.9.5のオクターブ自動判定

解析後は、各拍の検出メロディ音に近いコード構成音が鳴るように、コードの高さを自動で入れます。

例：

```text
検出メロディ：D3
コード：D
自動高さ：3
実際の構成音：D3 / F#3 / A3
```

別の例：

```text
検出メロディ：D3
コード：G
自動高さ：2
実際の構成音：G2 / B2 / D3
```

このように、コード名だけでなく「そのコードをどの高さで鳴らすとメロディに近いか」を見て初期値を入れます。

## オクターブ指定について

v0.9.4では、コードの高さを3段階で扱えます。

```text
1. 初期コードオクターブ
2. 小節全体の高さ
3. 各拍ごとの高さ
```

たとえば同じ `D` でも、

```text
高さ2：D2 / F#2 / A2
高さ3：D3 / F#3 / A3
高さ4：D4 / F#4 / A4
```

として再生・MIDI出力されます。

一部だけ低くしたい、高くしたい場合は、各拍の `高さ2 / 高さ3 / 高さ4 / 高さ5` を変更してください。

## ±1音ボタンについて

v0.9.9では、3.コード進行の手動調整用に、各拍へ以下のボタンを追加しています。

```text
−1音
＋1音
```

たとえば、

```text
Bb → B → C
Fm → F#m → Gm
```

のように、コードの種類は保ったまま、ルート音だけを半音ずつ上下できます。

小節全体にも、

```text
小節 −1音
小節 ＋1音
```

を追加しているので、1小節内の4拍をまとめて上下できます。

## コード選択肢の整理

コード選択肢は3段階で切り替えられます。

```text
基本：白鍵中心
標準：12音のメジャー/マイナー
拡張：dim / 7th も含む
```

現在入っているコードや抽出された候補コードは、選択肢モードに関係なくプルダウンに残ります。

## ドレミ表記について

最後の「確認・出力」の一番下に、以下の2種類を表示します。

### ドレミ表記（コード名）

```text
1小節目: [ド 高さ3] [レm 高さ3] [ファ 高さ3] [ソ 高さ3]
```

### ドレミ表記（実際に鳴る構成音）

```text
1小節目: 1拍:ド3/ミ3/ソ3  2拍:レ3/ファ3/ラ3
```

コードを作曲アプリへ手入力する時に、鍵盤上で確認しやすくするための表示です。

## MIDI出力の種類

### コードMIDI

選択中の拍マスに従って、コードを4分音符単位で出力します。
コードの高さは「コード全体のオクターブ」を反映します。

### メロディMIDI

鼻歌から検出したメロディをMIDIとして出力します。

### コード＋メロディMIDI

拍単位のコードと、検出メロディを同じMIDIファイルにまとめて出力します。

## v0.9.3の参考コード生成イメージ

検出メロディがこのような場合、

```text
D3 → Eb3 → F3 → Ab3
```

v0.9.3では、各拍の主メロディ音を見て、

```text
Dを含むコード
Ebを含むコード
Fを含むコード
Abを含むコード
```

を優先します。

ただし、コードは単音メロディをそのままコード名に変換するものではありません。
たとえば `D3` が検出されても、候補は `D` / `Dm` だけではなく、`G` / `Gm` / `Bb` など、D音を含むコードも選ばれる可能性があります。

## 重要な注意

この版のピッチ検出は、Basic Pitchのような本格的なAI音声解析ではありません。
ブラウザ内で動く軽量な簡易解析です。

そのため、以下の条件で精度が変わります。

- 鼻歌が小さすぎる
- 周囲の雑音が多い
- 息の音が大きい
- 音程が揺れすぎる
- 複数人の声や伴奏が入っている

## おすすめの録音条件

- 1人の鼻歌だけ
- 5〜20秒程度
- なるべく静かな場所
- スマホ/PCのマイクに近め
- 音程を少しはっきりめに歌う
